1- dentro da pasta "backend" rodar "npm install" 

2- docker run --name redis-mednotes -p 6379:6379 -d redis (essa etapa so precisa ser feita uma vez, para criar o container, caso já tenha feito pule para a etapa 3)

3- com o docker aberto no pc rodar "docker start redis-mednotes"

4- dentro da pasta "backend" rodar "node worker.js"

5- abrir outro terminal e dentro da pasta "backend" rodar "node index.js" (esse vai ser o servidor)

6- em outro terminal rodar "curl -X POST http://localhost:3000/consulta   -F "audio=@../audios/teste1.mp3"   -F "paciente=Fulano"   -F "data=20/06/2025"   -F "horario=12:45"
    nome data e horario pode ser qualquer um (so que deve seguir a mesma formatação desse exemplo e nao ser repetido). O campo "audio" deve receber o endereço do audio.
    vai retornar uma mensagem do seguinte formato "{"jobId":"13"}"

7- usando o jobId retornado na etapa anterior, podemos fazer  "curl -X GET http://localhost:3000/consulta/13" para consultar o estado do job (enquanto ele estiver rodando vai retornar
    "{"status":"active"}") quando o job for concluido no terminal do worker vai aparecer algo como "Script resumidor.py (args) completed / Summary done for job id=13". 
    Agora que o job foi concluido quando rodamos o GET com o jobId desse job concluido recebemos "{"status":"completed","resumo":"...","log":"..."} com o resumo concluido.
